# Chore

ColorOS 13.1 个人 APatch 模块。

- **高刷**：开机完成或点击操作按钮执行 `service call SurfaceFlinger 1035 i32 1`。本机模式 `1` 为 90Hz，其他机型需核对编号。
- **安装器**：[LineageOS 13 / APKMirror](https://www.apkmirror.com/apk/lineageos/package-installer-2/package-installer-2-13-release/package-installer-13-3-android-apk-download/)，要求 Android 13。
- **字体**：[Noto Sans CJK](https://github.com/notofonts/noto-cjk) 可变字体，元数据版本 2.004，SIL OFL 1.1 许可，配合 OPlus 字体配置使用。
